Recommended Voice Flow Design
Daily Check-in (~3-5 minutes)
Core Questions (Required):

Urges (3 questions)
Emotions (3 questions)
Actions (3 questions)
Medications (4 questions)

Skills Section (Adaptive):

Ask about skills only if user indicates they used skills (Used Skills > 0)
Use branching: "Which category of skills did you use today: Mindfulness, Interpersonal Effectiveness, Emotion Regulation, or Distress Tolerance?"
Then ask only about skills in selected categories

Weekly Check-in (~5-7 minutes, before therapy session)

Session urges (3 questions)
Belief in ability to regulate (3 questions)
Medication changes (1 question)
Homework review (1 question)
Skills focus (1 question)
